# Networking Basics Packet Tracer Labs

This folder contains a set of Cisco Packet Tracer activities designed to introduce and reinforce foundational networking concepts. Each lab focuses on a key idea in network design, communication, addressing, and device configuration.

## Overview

These exercises cover the core building blocks of computer networking, including:

- Local Area Networks (LANs)
- IP and MAC addressing
- DHCP configuration
- Wireless networking
- Client-server communication
- NAT and internet access
- Routing between networks
- Traffic flow and packet movement

The labs are intended for beginners learning how devices connect, communicate, and exchange data across a network.

---

## Lab Activities

### 1. Create a LAN
File: Create a LAN.pka

This lab introduces the basic design of a local network. Students learn how to connect devices such as PCs and switches, assign IP addresses, and verify communication within the same network segment.

Key concepts:
- LAN topology
- Ethernet connectivity
- Device addressing
- Basic connectivity testing
- Layer 2 switching

### 2. Configure DHCP on a Wireless Router
File: Configure DHCP on a Wireless Router.pka

This activity demonstrates how a wireless router can automatically assign IP addresses to clients through DHCP. Students configure the DHCP pool, default gateway, and network settings used by devices connecting to the wireless network.

Key concepts:
- DHCP server configuration
- IP lease assignment
- Default gateway
- Network addressing and scope configuration

### 3. Configure a Wireless Router and Client
File: Configure a Wireless Router and Client.pka

This lab shows how to set up wireless connectivity between a router and client devices. It introduces SSID configuration, wireless security, and making sure a wireless client can join the network successfully.

Key concepts:
- Wireless router setup
- SSID configuration
- Wireless security settings
- Client association
- WLAN basics

### 4. Connect to a Web Server
File: Connect to a Web Server.pka

This exercise explores client-server communication over a network. The client sends requests to a web server, and students observe how data is exchanged using Internet Protocols and application-layer services.

Key concepts:
- HTTP/HTTPS communication
- Client-server model
- Web browsing basics
- End-to-end connectivity

### 5. Examine NAT on a Wireless Router
File: Examine NAT on a Wireless Router Instructions.pka

This lab focuses on Network Address Translation (NAT), which allows devices on a private network to access external networks through a public IP address. It helps students understand how internal addresses are translated for communication outside the local network.

Key concepts:
- Private vs public IP addresses
- NAT and PAT
- Default gateway roles
- Internet access from private networks

### 6. Identify MAC and IP Addresses
File: Identify MAC and IP Addresses.pka

This exercise helps students distinguish between physical and logical addressing. It focuses on the roles of MAC addresses at Layer 2 and IP addresses at Layer 3 in a network transmission.

Key concepts:
- MAC addresses
- IP addresses
- Layer 2 vs Layer 3 addressing
- Address resolution and packet delivery

### 7. Observe Traffic Flow in a Routed Network
File: Observe Traffic Flow in a Routed Network.pka

This lab demonstrates how data moves across multiple networks through routers. Students observe traffic as it travels between different subnets and learn how routing decisions affect communication.

Key concepts:
- Routing between networks
- Default gateways
- Subnet communication
- Traffic analysis and packet forwarding

---

## Core Networking Concepts Covered

Across the labs, the following skills are developed:

- Understanding network devices such as PCs, switches, routers, and wireless access points
- Assigning and troubleshooting IP addresses
- Configuring DHCP for automatic client setup
- Identifying the purpose of MAC and IP addresses
- Explaining how wireless networks are established and managed
- Recognizing how NAT enables internet access for private networks
- Observing how packets move across local and routed networks

---

## Suggested Learning Sequence

To build a strong foundation, it is recommended to complete the labs in this order:

1. Create a LAN
2. Identify MAC and IP Addresses
3. Configure DHCP on a Wireless Router
4. Configure a Wireless Router and Client
5. Connect to a Web Server
6. Examine NAT on a Wireless Router
7. Observe Traffic Flow in a Routed Network

This sequence moves from simple local connectivity to more advanced networking concepts such as routing and address translation.

---

## Tools Used

This folder is designed for use with Cisco Packet Tracer, a network simulation tool used for learning and practicing routing, switching, wireless, and basic networking configuration tasks.

---

## Learning Outcome

By completing these activities, learners should be able to:

- Build and troubleshoot basic LANs
- Explain how IP and MAC addresses work together
- Configure DHCP and wireless network access
- Connect to web services and analyze network traffic
- Understand NAT and routing in real-world network scenarios
